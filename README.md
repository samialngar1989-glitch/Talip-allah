# Talip-allah | طالب الله

تطبيق ويب تقدمي (PWA) بسيط وخفيف، يهدف إلى [متجر تسوق عبر الانترنت].

## ✨ المميزات
*   يعمل كتطبيق ويب تقدمي (PWA) ويمكن تثبيته على الهاتف مباشرة.
*   يعمل بدون اتصال بالإنترنت (Offline) بفضل ملف `service-worker.js`.
*   تصميم بسيط ومتجاوب مع جميع أحجام الشاشات.
*   خفيف وسريع في الأداء.

## 🛠️ التقنيات المستخدمة
*   HTML5
*   JavaScript
*   PWA (Progressive Web App)

## 🚀 كيفية التثبيت والاستخدام
